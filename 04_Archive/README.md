# 📁 04_Archive

Folder ini berfungsi sebagai tempat penyimpanan untuk:
- Ide-ide mentah atau catatan *brainstorming* awal yang tidak dilanjutkan.
- Draf usang atau naskah iterasi sebelumnya.
- Paper komparasi atau literatur tambahan yang tidak jadi dimasukkan ke dalam daftar pustaka utama (misalnya referensi metode alternatif seperti SAW murni atau TOPSIS).
- Berkas sementara agar ruang kerja di folder `01_Literature_Notes`, `02_Evergreen_Notes`, dan `03_Manuscript_Draft` tetap bersih, terorganisir, dan fokus pada target publikasi.
